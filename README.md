# Horizonte Financeira

Site demonstrativo de uma financeira local, desenvolvido com HTML e CSS puro.

## Páginas

- `index.html`: página inicial e serviços
- `emprestimos.html`: opções de crédito, simulação visual e FAQ
- `cliente.html`: cadastro demonstrativo
- `css/style.css`: estilos compartilhados

## Como executar

Baixe ou clone o repositório e abra o arquivo `index.html` no navegador. No VS Code, também é possível usar a extensão Live Server.

> O simulador e o formulário são apenas demonstrativos. Nenhum dado é enviado ou armazenado. Uma futura versão com backend deverá incluir validação no servidor, autenticação, proteção do banco de dados, HTTPS e adequação à LGPD.
