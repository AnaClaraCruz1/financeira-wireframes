# Horizonte Financeira

Site demonstrativo de uma empresa do setor financeiro, desenvolvido como atividade acadêmica do curso Técnico em Desenvolvimento de Sistemas do SENAC.

O projeto foi desenvolvido a partir dos wireframes elaborados na atividade anterior, mantendo a proposta visual e a organização das telas, com pequenas adaptações necessárias para a implementação em HTML5 e CSS3.

**Autora:** Ana Clara Cruz

## Objetivo

Criar uma interface web para uma financeira, apresentando serviços de crédito, opções de empréstimos, uma simulação visual e um formulário demonstrativo para cadastro de clientes.

## Tecnologias utilizadas

- HTML5
- CSS3
- GitHub para versionamento e publicação do projeto
- Visual Studio Code para desenvolvimento

Não foram utilizados frameworks ou bibliotecas de front-end.

## Páginas

- `index.html` — página inicial, apresentação da empresa e serviços
- `emprestimos.html` — opções de empréstimo, simulador visual e perguntas frequentes
- `cliente.html` — página de cadastro demonstrativo

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador.
4. Para uma visualização mais prática durante o desenvolvimento, também é possível utilizar a extensão **Live Server** do Visual Studio Code.

As páginas possuem navegação por links internos entre si.

## Observações

O simulador de empréstimo e o formulário de cadastro são recursos demonstrativos para fins acadêmicos. O simulador representa visualmente uma possível interação, mas não realiza cálculos financeiros reais. O formulário não envia nem armazena dados.

Uma futura versão com back-end deverá incluir validação no servidor, autenticação, proteção dos dados, comunicação via HTTPS e adequação à LGPD.
